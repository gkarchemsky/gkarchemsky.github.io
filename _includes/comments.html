{%- comment -%} giscus — comments stored as GitHub Discussions. Renders nothing until `comments.repo_id` and `comments.category_id` are set in _config.yml, so the site is safe to deploy before any of it is configured. A post can opt out with `comments: false` in its front matter. How it works, in short: the script below injects an iframe from giscus.app. That iframe asks the giscus backend for the Discussion matching this page (matched on pathname, per `data-mapping`), renders it, and posts back its height. No Discussion is created until somebody actually comments — pages with no comments cost one request and show an empty box. Nothing here can post on your behalf: giscus is a GitHub *App*, scoped to the repositories it is installed on. (utterances, the older alternative, is an OAuth App that asks each commenter for the `public_repo` scope — write access to every public repository they own.
