{%- comment -%} Grouped in fours, driven by the actual length rather than a fixed ten groups: a v4 fingerprint is 40 hex chars, but a v6 key (RFC 9580) is 64, and hardcoding 40 would silently truncate it. The groups are accumulated into a string rather than emitted inline: a separator printed inside the loop sits next to whitespace-stripping tags and gets eaten before it reaches the output. {%- endcomment -%} {%- assign groups = fpr | size | divided_by: 4 -%} {%- assign grouped = "" -%} {%- for g in (1..groups) -%} {%- assign start = forloop.index0 | times: 4 -%} {%- assign chunk = fpr | slice: start, 4 -%} {%- if forloop.first -%} {%- assign grouped = chunk -%} {%- else -%} {%- assign grouped = grouped | append: " " | append: chunk -%} {%- endif -%} {%- endfor -%} {{ grouped }}
